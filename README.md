
# Tech Challenge — Fase 2

## Previsão de Intenção de Compra em E-commerce

Projeto de Machine Learning desenvolvido como parte do Tech Challenge da Pós-Graduação em Machine Learning Engineering da FIAP.

### Objetivo
Desenvolver um pipeline de Machine Learning para prever a intenção de compra de usuários em um ambiente de e-commerce.

### Tecnologias
- Python
- Scikit-learn
- MLflow
- DVC
- Poetry
- Git e GitHub
- Docker

### Modelos implementados
- Regressão Logística (baseline)
- Random Forest

### Métricas de avaliação
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Matriz de confusão

### Estrutura do projeto
- `src/data/`: preparação dos dados
- `src/training/`: treinamento dos modelos
- `src/evaluation/`: avaliação dos modelos
- `configs/`: configurações
- `tests/`: testes automatizados
- `reports/`: resultados e gráficos
- `data/`: dados versionados com DVC

### Status
Em desenvolvimento.
